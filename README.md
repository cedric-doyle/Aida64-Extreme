## 📘 About

AIDA64 Extreme is developed by FinalWire and is widely used to inspect what is inside a PC. It reads CPU, motherboard, memory, GPU, storage and network details, shows live temperature, voltage and fan readings from onboard sensors, and includes benchmark and stress test modules for checking stability and performance. Recent builds add support for newer chipsets, updated sensor logic and refreshed graphics and memory benchmark routines.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer will not start | Right click the setup file, choose **Run as administrator** and confirm the prompt. |
| Sensor values show as blank | Close other monitoring tools, then reopen AIDA64 Extreme so it can claim the sensor interface. |
| GPU details missing | Update the graphics driver from the adapter vendor and restart the machine. |
| Benchmark score looks low | Set the Windows power plan to High performance and close background apps before testing. |
| Reports fail to save | Choose a folder you have write access to, such as Documents, instead of a system path. |
| App closes during stress test | Stop the test, check CPU and GPU temperatures, and confirm the cooler is seated properly. |
